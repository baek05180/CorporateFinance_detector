# 기업 요약 작성 가이드

회사 화면의 '요약'(쉬운 말 한 줄 설명 · 돈 버는 구조 그림 · 해설)과 '사업' 카드는
`data/summaries/{고유번호}.json` 파일을 읽어 그린다. 이 파일은 사람이 아니라 Claude가
`python -m tools.summary_queue` 가 내준 재료(사업보고서 II. 사업의 내용 1~4절 압축 원문 + 재무)를
읽고 쓴다. 다 쓰면 `python -m tools.summary_check` 로 형식을 검사한다.

## 원칙

1. **재료에 있는 사실만 쓴다.** 숫자(매출 비중·금액·고객사 비중)는 재료에 그대로 있는 것만. 계산은
   재료 숫자끼리 나눈 정도만 허용(예: 부문 매출 ÷ 총매출). 모르면 비운다(`null`). 추측 금지.
2. **쉬운 말.** 업계 용어를 처음 보는 사람도 이해하게 쓴다. "~를 만들어 ~에게 팔아 돈을 버는 회사입니다." 구조.
3. **잘린 문장 금지.** 모든 문장은 끝맺는다. "…"으로 끝내지 않는다.
4. 회사명은 화면 표시 이름(재료의 `name`)을 쓴다. 존댓말 평서문(~입니다)은 한 줄 설명·사업·매출처에, 해설(caption)은 간결한 서술체(~다)도 된다.

## 형식

```json
{
  "corp_code": "01275665",            // 재료의 corp_code 그대로
  "name": "리메드",
  "source_rcept": "20260317000860",   // 재료의 annual_rcept 그대로 (어떤 사업보고서를 읽었는지)
  "source_name": "사업보고서 (2025.12)",
  "written": "2026-10-26",
  "one_liner": "리메드는 강한 자석 힘(자기장)으로 몸 밖에서 신경을 자극해 허리·무릎 통증과 우울증을 치료하는 병원용 기계를 만들어, 그 절반 이상을 독일 짐머 같은 해외 의료기기 회사·대리점에 팔아 돈을 버는 회사입니다.",
  "facts": "설립 2003.07 · 코스닥 2019.12 · 50여 개국 수출",          // 120자 이내, 재료에 있는 사실만
  "mix_line": "매출 만성통증 59.1% · 뇌재활(TMS) 16.8%",             // 60자 이내, 매출 구성 상위 1~3개
  "flow": {
    "inputs":    [{"name": "기구·전자부품", "note": "원재료 74억"}],            // 0~3개 (원재료·외주·상품 매입)
    "company":   {"name": "리메드", "note": "자기장 치료기 제조 (오송·대전)"},
    "customers": [{"name": "독일 짐머(Zimmer)", "note": "ODM 납품 · 매출 26.4%"}], // 1~4개 (고객 유형 또는 회사명)
    "revenue":   [{"name": "만성통증 치료기", "amount": 13790000000, "share": 59.1}], // 1~6개, amount는 원 단위 숫자, 모르면 null
    "basis": "2025 별도"              // 매출 구성 숫자의 기준
  },
  "caption": "돈을 버는 중심은 만성통증 치료기(매출의 59%)이고 …",   // 260자 이내. 그림을 읽는 법·이익 엔진·변화 포인트
  "business": "2~4문장 사업 설명",                                 // 400자 이내
  "products": [{"name": "Salus Talent Pro", "segment": "만성통증", "desc": "근골격계 통증 치료기", "share": 59.1}], // 최대 6개
  "customers": "주요 매출처를 1~2문장으로"                          // 220자 이내
}
```

- `share` 는 % 숫자(59.1), `amount` 는 원 단위 정수. 재료 표의 단위(천원·백만원)를 꼭 확인해 원으로 바꾼다.
- 매출 구성이 재료에 없으면 `revenue` 에 부문 이름만 넣고 `share`·`amount` 를 `null` 로 둔다.
- 금융지주·지주회사처럼 '사 오는 것'이 없으면 `inputs` 는 빈 배열.
