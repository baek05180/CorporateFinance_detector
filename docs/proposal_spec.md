# 공모 회사채 발행제안서 명세

조달 제안 보고서 > 공모 회사채 > **[공모사채 제안서 작성 (PPT)]** 버튼으로 만드는 제안서의 구성과 규칙이다.
이 파일이 원본이다. 아래 `설정` 블록(yaml)을 고치면 다음 제안서부터 자동 반영된다 — GitHub 웹에서 이 파일을 열고 연필 아이콘으로 고친 뒤 커밋하면 된다.

- 팝업 입력 항목, 기본 문구, 한·미 이벤트, 휴일, 시장 코멘트, 금통위·Fed 위원 성향, FedWatch 확률, 문구 기준값, 장표 켜기/끄기는 `설정` 블록에서 바로 바뀐다.
- 새 장표·새 계산은 코드(`tools/proposal5.py`, `tools/proposal_text.py`, `tools/proposal_mkt.py`) 수정이 필요하다.
- 목표: **회사 등급·데이터로 모든 숫자와 문장을 자동으로 채워, 최소한의 확인만 거쳐 발행 희망 회사에 보낼 수 있게** 한다. 데이터가 없을 때만 빨간 `##` 이 남는다.
- 이 저장소는 공개다. 이 파일에 고객사 이름·기밀 내용을 쓰지 않는다.

## 1. 데이터

| 구분 | 내용 | 출처 (자동 수집) |

| 팝업 입력 | 납입일, 수요예측일, 발행금액 기본·최대, 만기별 금액, 증액 우선 만기, 금리밴드, 인수수수료, **개별민평(선택)**, 이슈·크레딧 메모 | 팝업 |

## 2. 기준 민평과 예상 금리

만기별 **기준 민평**은 아래 순서로 정한다. 장표에는 어떤 기준을 썼는지 함께 표시한다.

1. 팝업에 입력한 **개별민평** (예: `2:4.21,3:4.35,5:4.62`) — 평가사 단말에서 확인한 값
2. **추정 개별민평** = 동사 등급의 등급민평 + 동사 고유 스프레드. 고유 스프레드는 최근 30일 장외 체결(거래대금 1억원 이상, 잔존 9개월 이상, 사모·후순위 제외, ±150bp 이상치 제외)의 `체결 수익률 − 같은 잔존만기 등급민평` 거래대금 가중 중앙값. 3건·20억원 이상일 때만 쓴다.
3. 동사 등급의 **등급민평**

**목표 가산금리** = (동사 직전 회차 확정 가산금리, 같은 등급군 최근 6개월 확정 가산금리 중앙값)의 평균을 금리밴드 안으로 자른 값.
**예상 확정금리** = 기준 민평 + 목표 가산금리. 금리밴드도 기준 민평에 더해 금리(%)로 환산해 보여 준다.

등급군: AAA / AA(AA+·AA·AA-) / A(A+·A·A-) / BBB. 수요·사례·만기 통계는 같은 등급군, 프라이싱 사례는 같은 등급 ±1노치.

## 3. 장표별 내용 규칙

| 장표 | 자동으로 쓰는 내용 |
|---|---|
| 권고안 요약 | 예상 금리(만기별), 일정, 평가사별 등급·전망 / 근거 3개: 수요(직전 회차 또는 같은 등급군 6개월), 금리(등급 3년 스프레드·1년 분위·1개월 변화), 동사 신용(장외 거래 스프레드) 또는 일정(이벤트·만기 재투자) / 리스크·대응(스프레드 분위, 같은 등급군 미매각·경합) / 등급민평·추정 개별민평·국고 3년 6개월 추이 |
| 발행조건 | 발행금액 근거(만기도래·자금 수요·시장 수급), 만기 근거(만기별 국고 대비 스프레드·기간 프리미엄, 수요, 만기 분산), 금리밴드 금리 환산, 예상 발행금리(기준 민평+목표 가산), 평가사별 등급·전망·평가일 |
| 예상 발행금리 | 만기별 등급민평·기준 민평·밴드 하단/목표/상단·국고 대비 / 같은 등급 ±1노치 최근 사례 / 근거 카드 3개 |
| 트랜치 | 만기별: [금리] 등급민평·국고 대비·앞 만기 대비 기간 프리미엄·스프레드 1개월 변화, [수급] 같은 등급군 6개월 건수·주문·경쟁률·확정 가산 중앙값·미매각, [동사] 직전 회차, [만기] 연도별 만기 / 우측 비교표 |
| 옵션 | 옵션별 최대 구성의 평균 예상금리(가중평균), 기간 프리미엄(bp), 만기 영향 |
| 발행 일정 | 이벤트 전 금리 확정, 발행월 같은 등급군 만기(재투자 수요), 수요예측 ±1주 경합 발행, 작년 같은 달 발행·경쟁률, 스프레드 수준 |
| 직전 회차 | 수요예측 결과가 없으면 아는 값 + `##` |
| 크레딧 스토리 | 사업(사업보고서 요약·매출 구성) / 실적(매출·영업이익·EBITDA) / 재무·유동성(현금성자산 vs 12개월 만기, 영업현금흐름, 순차입금/EBITDA) / 신용도(평가사별 등급·전망, 최대주주, 장외 스프레드). 팝업 '크레딧 포인트' 메모가 있으면 맨 앞. |
| 예상 질문 | 기준값을 넘는 지표만 질문으로: 부채비율, 이자보상배율, 순차입금/EBITDA, 투자>영업현금흐름, 등급 전망·하향 트리거, 12개월 차환, 수익성 — 답변 방향은 공시 수치로 |
| 대시보드 | 기준금리·국고 3/10년·동사 등급 3년·스프레드·AA-(참고)·CP·美 / 발행 영향 한 줄(스프레드 분위·1개월 변화 조합) |
| 크레딧 시장 | 동사 등급 3년 금리·국고·스프레드 1년 차트, 스프레드 1년 범위·분위·3개월 변화, AA- 대비 등급 간 차이, 같은 등급군 수요·미매각, 동사 장외 스프레드 + `market_view.credit` |
| 한국 / 미국 | 국고 3년−기준금리 차이로 시장 반영 방향, 1개월 변화, 장단기 차 / 美 2년−정책금리 중간값 + `market_view.kr` / `market_view.us` |
| FedWatch 표 | `fedwatch.probs` 에 입력한 값. 비어 있으면 `##` (CME 이용약관상 자동 수집하지 않음) |
| 전망 시나리오 | 리서치 엑셀 연동 전까지 `##` |

`market_view` 는 `asof` 로부터 `rules.market_view_max_age_days`(기본 10일)가 지나면 자동으로 빠지고 자동 문장만 남는다.

## 4. 전망 엑셀 업로드 양식 (예정)

- 시트 `전망` 1개. 이름 정의 `FCST_TABLE`(행: 기준금리·국고 3년·동사 등급 3년·스프레드·美 FF 상단 / 열: 3개월 기본·낙관·비관, 6개월 기본), `FCST_SCEN`(기본·낙관·비관 × 확률·근거1·근거2·시사점), `FCST_DATE`, `FCST_HEADLINE`, `FCST_SOURCE`.

## 5. 레이아웃 규칙

- 상단 회색 요약 박스는 마지막 줄 바로 아래까지만 둔다. 남는 공간은 아래 그래프·표가 가져간다(같은 열에선 맨 위 요소만 커짐). 생성 마지막 단계에서 자동 처리.
- 투자자 배포(IR) 자료로 옮길 때는 신용지표 원수치 대신 일시적 요인과 대응 논리 중심으로 바꾼다.
