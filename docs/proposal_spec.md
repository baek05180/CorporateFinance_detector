# 공모 회사채 발행제안서 명세

조달 제안 보고서 > 공모 회사채 > **[제안서 작성(PPT)]** 버튼으로 만드는 제안서의 구성과 규칙이다.
이 파일이 원본이다. 아래 `설정` 블록(yaml)을 고치면 다음 제안서부터 자동 반영된다 — GitHub 웹에서 이 파일을 열고 연필 아이콘으로 고친 뒤 커밋하면 된다.

- 팝업 입력 항목, 기본값, 한·미 이벤트 일정, 휴일, 장표 켜기/끄기, 레이아웃 값은 `설정` 블록에서 바로 바뀐다.
- 새 장표 추가처럼 새 계산이 필요한 변경은 코드(`tools/proposal5.py`) 수정이 필요하다.
- 값을 확정할 수 없는 칸은 빨간 `##` 로 남는다. PowerPoint에서 `##` 를 검색해 채운다.

## 1. 데이터 구분

| 구분 | 내용 | 출처 |
|---|---|---|
| 팝업 입력 | 납입일, 수요예측일(선택), 발행금액 기본·최대, 만기별 금액, 증액 우선 만기, 금리밴드, 인수수수료, 최근 이슈·크레딧 포인트 메모 | 팝업 |
| 사이트 보유 데이터 | 회사명, 신용등급, 직전 회차 수요예측 결과(기관군별 참여·가산금리·확정금리), 공모사채 만기 사다리, 재무 | `data/` (OpenDART, 채권기본정보) |
| 시장 데이터 | 국고·AA- 3년·CP 91일·기준금리, 美 국채·FF | `data/ref/mkt/rates.json` (ECOS·FRED, 매일 수집) |
| 시장 코멘트 | 한국·미국 시장 요약 문장 | `data/manual/market_comment.json` (수기) |
| 이벤트 일정 | 금통위, FOMC, 美 CPI, 휴일 | 아래 `설정` 블록 |
| 정기 업로드 (예정) | 3·6개월 전망치, 시나리오 | 리서치 엑셀 (3절) |
| 최종 수기 입력 `##` | 개별민평, 예상 확정금리, 수수료(미입력 시), FedWatch 확률 | 작성자 |

## 2. 장표 구성

1 표지 / 2 Disclaimer / 3 Executive Summary
I. 발행 제안: 발행조건 / 예상 발행금리·프라이싱 사례 / 사채 만기구조 Before·After / 트랜치 / 만기 옵션 A·B / 발행 일정 캘린더
II. 세일즈 전략: 직전 회차 결과 / 크레딧 스토리·투자자 Q&A
III. 시장 동향: 대시보드 / 전망 시나리오 / 크레딧 / 한국 / 금통위 / 미국 + FedWatch / Fed 위원 / 다음 연도 만기
Appendix: 발행월·다음 달 만기 / 동일 등급 발행 내역

## 3. 전망 엑셀 업로드 양식 (예정)

- 시트 `전망` 1개. 이름 정의 `FCST_TABLE`(행: 기준금리·국고 3년·AA- 3년·AA- 스프레드·美 FF 상단 / 열: 3개월 기본·낙관·비관, 6개월 기본), `FCST_SCEN`(기본·낙관·비관 × 확률·근거1·근거2·시사점), `FCST_DATE`, `FCST_HEADLINE`, `FCST_SOURCE`.
- 업로드 → 파싱 → 검증(빈칸·숫자·확률 합 100%) → 전망 장표에 주입. 연결 전까지 전망 장표는 `##`.

## 4. 데이터 수집 경로

| 항목 | 경로 | 비고 |
|---|---|---|
| 시장금리 | ECOS `817Y002` (국고 3·5·10년, AA- 3년, CP 91일 `010503000`) | 매일 수집 |
| 직전 회차 수요예측 | 투자설명서 "수요예측 참여 내역" | `data/ref/mkt/demand.json` |
| 신용등급·평가사 | 증권신고서, 평가사 보고서(수기 `data/manual/rating_triggers.csv`) | 평가사 목록이 없으면 `##` |
| FedWatch | CME FedWatch → Probabilities | 이용약관상 자동 수집 대신 작성 시점 수기 입력 |

## 5. 레이아웃 규칙

- 상단 회색 요약 박스는 마지막 줄 바로 아래까지만 둔다. 남는 공간은 아래 그래프·표가 가져간다(같은 열에선 맨 위 요소만 커짐). 생성 마지막 단계에서 자동 처리.
- 신용지표 원수치(순차입/EBITDA 등)는 외부 배포용 장표에 쓰지 않는다.
